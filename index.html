PROJECT 02 MODERNIZATION
SYSTEM ANALYST · MAINFRAME MODERNIZATION

Claims
Modernization

Part of a Mainframe modernization initiative aimed at migrating legacy COBOL claims-processing logic toward a modern Java-based architecture. As System Analyst, analyzed existing Mainframe modules — including COBOL programs, Copybooks, and DB2 table structures — to understand both the business logic and the underlying data definitions it depended on. Authored corresponding natural-language specifications for each: translating COBOL program logic, Copybook record layouts, and DB2 table-based data structures into structured, natural-language modules, broken into small, precise units, which were processed through an automated toolchain to generate equivalent Java code.

Worked within Visual Studio to author and refine these natural-language specifications, bridging deep Mainframe domain knowledge with the modernization workflow — ensuring the generated Java logic and data structures accurately preserved the original COBOL system's behavior.

Supported eHub, a claims and membership data integration layer connecting Mainframe systems with modern downstream applications via Service-Oriented Architecture (SOA). Developed and modified JCL to run scheduled batch jobs that called Mainframe systems and loaded data from Mainframe sources into eHub tables, feeding front-end applications including the Provider Portal and Member Portal with accurate, up-to-date claims and membership data. Performed root-cause analysis on integration issues and production defects affecting this data pipeline, working across application and integration teams to identify failures and implement corrective fixes — helping maintain reliable data flow to the customer-facing portals that depended on it.

KEY ACHIEVEMENTS
  • Identified recurring root causes behind failed batch jobs and implemented corrective fixes, reducing job failures and reruns in the eHub data pipeline
  • Analyzed the batch job flow and restructured job scheduling to run eligible jobs in parallel rather than sequentially, reducing overall data load time
